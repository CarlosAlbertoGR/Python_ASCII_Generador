🎨 Generador de Arte ASCII con Interfaz Gráfica (Python/Tkinter)

Este proyecto es una herramienta de escritorio construida en Python que permite a los usuarios seleccionar cualquier imagen (JPG, PNG) y transformarla en arte ASCII, representando los tonos de brillo con caracteres de texto.

La aplicación utiliza la librería estándar **Tkinter** para la interfaz gráfica, permitiendo una interacción amigable y eliminando la necesidad de usar la terminal para la selección de archivos.

✨ Tecnologías Utilizadas
* **Python 3.x:** Lenguaje principal.
* **Tkinter:** Librería estándar para la Interfaz Gráfica de Usuario (GUI).
* **Pillow (PIL):** Para la manipulación y procesamiento de imágenes (redimensionado, conversión a escala de grises).

🚀 Cómo Ejecutar
python generador_ascii.py   
1. Requisitos
Asegúrate de tener Python instalado (versión 3.6 o superior).
